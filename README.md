# My Gallery

## Third-Party Library
| Library | Version | Why |
|---|---|---|
| [GoogleSignIn-iOS](https://github.com/google/GoogleSignIn-iOS) | 10.0.0 | Google login |

Added with Swift Package Manager. No other third-party libraries.

## Image API
[Picsum Photos](https://picsum.photos), free and public, no API key needed.

- List: `https://picsum.photos/v2/list?page=1&limit=20`
- Image: `https://picsum.photos/id/{id}/{width}/{height}`

## How to Run
1. Open `MyGallery.xcodeproj` in Xcode.
2. Wait for Swift packages to download.
3. Run on a simulator or iPhone.
